This folder stores the raw daily NASA POWER CSV files and the processed outputs generated by the notebook/script.

After executing the workflow, the following files are expected:

- `raw/power_daily_2016.csv` ... `raw/power_daily_2025.csv`
- `processed/combined_daily_data.csv`
- `processed/monthly_summary.csv`
- `processed/annual_summary.csv`
- `processed/validation_report.csv`
